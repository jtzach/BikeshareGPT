# v1.1 correction release — 16 November 2026

v1.1 contains 290 active tasks (100 semantics, 100 retrieval, 90 synthesis). The original 300-task v1 bundle and all historical model outputs remain unchanged.

- Corrected two unsupported targets with explicit null contracts.
- Resolved 25 ambiguous questions through population, missingness, duplicate-counting, ranking, distance and semantic rules.
- Balanced all semantic answer positions to 25 per letter with recorded option mappings.
- Retired all ten plotting tasks (synthesis 081–090). File existence did not establish chart correctness; no replacement semantic plot metric is claimed.
- Normalized `time_zone` to `timezone` in the separate snapshot copy.
- Added strict JSON, version/task fingerprints, deterministic migration and independent reference checks.
- Versioned grading as 1.1.0: reject fractional integer matches, Boolean counts, nonfinite numeric targets and implicit/failed null answers.
- Bound resumable runs to inputs, prompts, code, environment versions and effective endpoints.
- Disabled optional GPT-5 sanity adjudication by default.
- Replaced the historical histogram few-shot example with a positive reported-capacity calculation; original examples are preserved.
- Added three reproducible scientific figures and framework documentation.

Validation: 290/290 reference matches, 369/369 dataset checks and 47 passing offline regression tests. Individual schemas: nine pass, one expected relative-URL deviation, zero unexpected failures. See the [evidence](../../validation/v1_1/README.md), [migration](../../benchmarks/gbfs_mv_rad_v1_1/migration.json) and [frozen report](../../benchmarks/gbfs_mv_rad_v1_1/validation_report.json).

Use `configs/mv_rad_v1_1_suite.yaml` and a fresh run directory. No new model-performance evaluation was performed; historical scores cannot be relabelled as v1.1. Licensing, archival identifier and historical provenance gaps remain documented.
